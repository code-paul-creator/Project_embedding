How Mathematical PCA Projection Works: Each word begins as a 16-dimensional continuous feature vector $\mathbf{x} \in \mathbb{R}^{16}$. We construct the mean-centered data matrix $\mathbf{X}_c = \mathbf{X} - \boldsymbol{\mu}$ and compute the $16 \times 16$ covariance matrix $\mathbf{C} = \frac{1}{N-1}\mathbf{X}_c^T \mathbf{X}_c$. Using the Jacobi Eigenvalue Algorithm, we extract the top 3 eigenvectors $[\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3]$ corresponding to the largest eigenvalues. Projecting $\mathbf{z}_i = \mathbf{x}_{c, i} \cdot [\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3]$ yields the $(x, y, z)$ coordinates that preserve maximum semantic variance without arbitrary random numbers.

NLP Learning Knowledge Base

Theory, Definitions & Mathematical Formulations
1. What is a Vocabulary?

A vocabulary ($\mathcal{V}$) is the finite set of distinct, recognizable linguistic units (words, subwords, or characters) that a natural language model knows. The size of the vocabulary is denoted as $|\mathcal{V}|$. Any word not contained in $\mathcal{V}$ is classified as Out-of-Vocabulary (OOV) and is usually replaced by an unknown token `[UNK]`.

2. What is a Token & Tokenization?

Tokenization is the foundational preprocessing stage in NLP that segments continuous raw text into discrete atomic chunks called tokens.

  • Word-level: Splits by spaces and punctuation. Yields large vocabularies and suffers from OOV on new words.
  • Character-level: Splits text into individual letters/characters. Small vocabulary, but creates extremely long token sequences that degrade model memory.
  • Subword-level (BPE / WordPiece): Deconstructs frequent words as whole tokens and rare/inflected words into subword roots (e.g. unbreakable → un + ##break + ##able). Balances vocabulary compactness and infinite expressiveness.
3. What is a Token ID?

Computers cannot process raw strings; neural networks operate strictly on mathematical tensors. A Token ID is a unique integer index assigned to each token in the vocabulary lookup dictionary:

\text{Token} \xrightarrow{\mathcal{V}} \text{Integer ID} \quad \text{e.g., } "neural" \mapsto 4129, \quad "network" \mapsto 2897

This integer acts as the row index into the model's embedding matrix $\mathbf{W}_e \in \mathbb{R}^{|\mathcal{V}| \times d}$.

4. What are Vector Embeddings?

A word embedding is a continuous, dense vector representation $\mathbf{e} \in \mathbb{R}^d$ where words with similar contextual meanings reside close to each other in vector space (the Distributional Hypothesis: "A word is characterized by the company it keeps").

  • Sparse One-Hot: High-dimensional vector of size $|\mathcal{V}|$ with a single 1 and all 0s. Zero semantic similarity between words.
  • Dense Embeddings: Low-dimensional continuous vectors ($d = 128 \dots 4096$) capturing semantic analogies such as $\mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}} \approx \mathbf{v}_{\text{queen}}$.
5. What is Cosine Similarity?

Cosine Similarity computes the cosine of the angle $\theta$ between two non-zero vectors $\mathbf{u}$ and $\mathbf{v}$. It measures directional alignment irrespective of vector magnitude:

\text{Cosine Similarity}(\mathbf{u}, \mathbf{v}) = \cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \frac{\sum_{i=1}^d u_i v_i}{\sqrt{\sum_{i=1}^d u_i^2} \sqrt{\sum_{i=1}^d v_i^2}}

Values range from $-1.0$ (diametrically opposite) to $+1.0$ (identical direction), with $0.0$ indicating orthogonality (no correlation).

6. Dimensionality Reduction & PCA (Principal Component Analysis)

Word embeddings exist in high dimensions ($d = 16 \dots 1536$), which humans cannot visually perceive. Dimensionality Reduction projects high-dimensional data into 2D or 3D while preserving as much structural variance as possible.

PCA Step-by-Step Procedure:

  1. Center the Data: Subtract the mean feature vector $\boldsymbol{\mu} = \frac{1}{N}\sum_{i=1}^N \mathbf{x}_i$ so that $\mathbf{X}_c = \mathbf{X} - \boldsymbol{\mu}$.
  2. Compute Covariance Matrix: $\mathbf{C} = \frac{1}{N-1}\mathbf{X}_c^T \mathbf{X}_c \in \mathbb{R}^{d \times d}$.
  3. Eigenvalue Decomposition: Solve $\mathbf{C} \mathbf{v}_k = \lambda_k \mathbf{v}_k$ using the Jacobi eigenvalue algorithm.
  4. Sort Eigenvectors: Rank by descending eigenvalues $\lambda_1 \ge \lambda_2 \ge \lambda_3 \dots$.
  5. Linear Projection: Project each centered vector onto the top 3 principal axes: $\mathbf{z}_i = \mathbf{x}_{c, i} \cdot [\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3]$.
